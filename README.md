# 📦 Supply Chain Control Tower & Inventory Intelligence

📊 End-to-end Supply Chain dashboard project using **Power BI, Power Query, and DAX**.

## 📌 Project Overview
- Analyzed 1,200 supply chain records (2020–2024) across categories, suppliers, warehouses, and regions.
- Cleaned the data and built a date table with a one-to-many relationship in Power BI.
- Created KPIs: Backorder Rate %, Inventory Turnover, Capacity Utilization %, Average Lead Time, Order Accuracy %, and Transport Cost per Unit.
- Built an interactive dashboard with slicers, a backorder heatmap, a supplier speed-vs-accuracy chart, and trend charts.

## 🔍 Key Insights
- Furniture in Warehouse 3 has a **16.0% backorder rate**, against 8.4% for the warehouse as a whole.
- Warehouses use only about **34% of their capacity**, so the issue is stock allocation, not space.
- **North** has the highest volume (170K units) and the highest backorder rate (11.0%).
- **Supplier A** leads on speed and accuracy; **Supplier D** has the highest backorder rate (12.2%).
